# CPSS DCC LaTeX manuscript

This directory is a working manuscript based directly on the official DCC LaTeX package (`dccpaper.cls`, `IEEEbib.bst`). The main source is `main.tex`; bibliography entries are in `refs.bib`.

Build on Windows with MiKTeX:

```powershell
xelatex -interaction=nonstopmode -halt-on-error -jobname=dcc_paper main.tex
bibtex dcc_paper
xelatex -interaction=nonstopmode -halt-on-error -jobname=dcc_paper main.tex
xelatex -interaction=nonstopmode -halt-on-error -jobname=dcc_paper main.tex
```

The manuscript contains the audited quantitative results and the current author metadata. Figure 1 uses the color PDF export `Figures/cpss_architecture_color.pdf` (PNG preview also included); `Figures/cpss_architecture_color.drawio` is a large, readable editing draft with the same system logic. Figure 2 uses `Figures/timing_boundary_color.pdf`, with editable source `Figures/timing_boundary_color.drawio`. Figures 3 and 4 use a consistent Raw/Zstandard/CPSS palette, with hatches and markers retained as secondary cues. Regenerate the redesigned color schematics and quantitative figures from the repository root with:

```powershell
python Script/create_dcc_advanced_figures.py
python Script/plot_dcc_two_figures.py
python Script/plot_dcc_revision_figures.py --data-root ExperimentRecords/dcc_paper_dataset_20261004 --output docs/dcc_latex/cpss_submission/Figures
```

Quantitative result plots are generated by `Script/plot_dcc_two_figures.py` from the audited analysis outputs. The English submission source is `main.tex`; the Chinese reading translation is `main_zh.tex` and is not the submission source. The citation/related-work map is at `../../DCC_related_work_citation_map.md`. DCC's official package is archived one directory above in `official_template/`; the downloaded ZIP is `DCCTemplateLaTeX.zip`.
